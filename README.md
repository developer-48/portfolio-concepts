Статический проект для GitHub Pages. Дизайн и разработка — Юсуп Сагариев.

- [FORMA — архитектурное бюро](https://developer-48.github.io/portfolio-concepts/forma/)
- [MORI — кофейня](https://developer-48.github.io/portfolio-concepts/mori/)
- [LUMA — интерьерный свет](https://developer-48.github.io/portfolio-concepts/luma/)

## Что внутри

FORMA: архитектурный проект, материалы, этапы, раскрытие проекта и локальный бриф.

MORI: меню из шести позиций, фильтры, настройка объёма и молока, пересчёт цены, демонстрационный список выбора и рецепты.

LUMA: три предмета коллекции, настройка света, образцы дерева и локальное сохранение параметров. Свечение стилизовано; материал отражается на образце.

Портфолио: 39 Donuts, публичный лендинг KF21, три личных концепта и текстовые описания KF21 и BronService. Редизайн 39 Donuts показан как демонстрация. Закрытых экранов бизнес-систем нет.

Три концепта используют вымышленные бренды, предметы и характеристики. Реальные заказы, платежи и отправка заявок не выполняются. Содержимое форм остаётся на устройстве посетителя.

## Локальный запуск

Сборка и установка зависимостей не требуются. Из корня:

```sh
python3 -m http.server 4195 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4195/`.

## Публикация

GitHub Pages настроен на ветку `main`, корень репозитория. Файл `.nojekyll` сохраняет обычную статическую публикацию. Все локальные пути относительные и совместимы с размещением в подпапке Pages.

## Движение

GSAP и ScrollTrigger управляют появлением блоков, изображениями и реакцией на скролл. В портфолио Three выводит фон, который тянется к курсору. Ограничены разрешение и частота отрисовки, фон останавливается после бездействия и вне первого экрана. При `prefers-reduced-motion`, сенсорном указателе или недоступном WebGL доступна статичная композиция.

Шрифты, библиотеки и изображения локальные. Аналитика, cookies, внешние формы и платёжные интеграции отсутствуют.

Описание изображений и лицензии: [ASSETS.md](ASSETS.md). Проверки: [QA.md](QA.md).
